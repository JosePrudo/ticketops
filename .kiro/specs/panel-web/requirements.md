# Requisitos: panel web

- WHEN se abre el panel THE SYSTEM SHALL mostrar tickets e indicadores de abiertos, vencidos y resueltos.
- WHEN se crea un ticket sin título THE SYSTEM SHALL mostrar un error y enfocar el título.
- WHEN se selecciona una acción THE SYSTEM SHALL ofrecer únicamente transiciones permitidas y solicitar nota al resolver.
- WHEN un ticket está vencido THE SYSTEM SHALL identificarlo con el texto VENCIDO.
- WHEN falla la conexión THE SYSTEM SHALL mostrar un mensaje comprensible y permitir reintentar.
- THE SYSTEM SHALL permitir el uso con teclado, etiquetas accesibles, foco visible, diálogo modal y visualización a 375 px sin desplazamiento horizontal.
- THE SYSTEM SHALL insertar los datos de solicitantes como texto y respetar `prefers-reduced-motion`.

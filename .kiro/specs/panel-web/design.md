# Diseño: panel web

El panel en `/panel/` utiliza HTML, CSS y JavaScript nativos. Incluye indicadores, formulario de alta, filtros, tabla adaptable y diálogo de resolución. Los mensajes de carga, vacío y error se anuncian mediante regiones accesibles. El contenido ingresado se inserta como texto, nunca como HTML. En pantallas pequeñas las filas se presentan como tarjetas sin desplazamiento horizontal.
